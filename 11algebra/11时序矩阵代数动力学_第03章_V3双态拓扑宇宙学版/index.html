    §3.1 韦达跳跃算子 \(\mathcal{T}_x, \mathcal{T}_y, \mathcal{T}_z\) 的形式化定义¶

    3.1.1 从马尔可夫方程到韦达跳跃的代数必然性¶

    在 §2.1 中，我们从公理一（净余能量唯一本源）和公理三（拓扑态名额排他性）推导出了马尔可夫丢番图方程：

    \[ x^2 + y^2 + z^2 = 3xyz \]

    其中 \(x, y, z \in \mathbb{Z}^+\) 是由公理三赋予的拓扑名额聚集度（Topological Quotas），每个名额不可再分、不可重叠。

    本节的核心任务是：定义作用于节点 \(P=(x,y,z)\) 上的韦达跳跃算子，并证明它们是拓扑态侧名额重排的唯一合法代数操作。

    【名相注（V3）】 下文凡出现「根域」，一律读作拓扑态侧（本体侧）；凡出现「冠」「表象空间」，一律读作表象态侧。二者不是两个世界，是同一个本体的两个面（第一层双态），共享同一套时空。

    3.1.2 韦达跳跃算子的代数定义¶

    韦达跳跃的数学原理源于韦达定理（Vieta's formulas）。固定 \(y\) 和 \(z\) 不变，将马尔可夫方程视为关于 \(x\) 的二次方程：

    \[ x^2 - (3yz)\, x + (y^2+z^2) = 0 \]

    该方程的两个根 \(x_1, x_2\) 满足：

    \[ x_1 + x_2 = 3yz, \qquad x_1 x_2 = y^2 + z^2 \]

    若 \((x, y, z)\) 是一个已知解，则另一个根 \(x' = 3yz - x\) 也给出一个新的正整数解 \((x', y, z)\)。这就是韦达跳跃。

    【定义 3.1.1（韦达跳跃算子）】 对任意节点 \(P = (x, y, z) \in \mathcal{V}_{\text{M}}\)，定义三个韦达跳跃算子：

    \[ \hat{\mathcal{T}}_x(P) = (3yz - x,\; y,\; z) \]
    \[ \hat{\mathcal{T}}_y(P) = (x,\; 3xz - y,\; z) \]
    \[ \hat{\mathcal{T}}_z(P) = (x,\; y,\; 3xy - z) \]

    即保持其余两个坐标不变，将第 \(k\) 个坐标替换为 \(3\times(\text{另两个坐标之积})-(\text{原第 }k\text{ 个坐标})\)。

    【定理 3.1.1（韦达跳跃的名额守恒定理）】 对任意 \(P \in \mathcal{V}_{\text{M}}\) 和任意 \(k \in \{x,y,z\}\)，\(\hat{\mathcal{T}}_k(P)\) 仍然是马尔可夫方程的正整数解。

    证明（原文保留，一字未改）： 设 \(P=(x,y,z)\) 满足方程。令 \(x' = 3yz - x\)。则

    \[ x'^2 = (3yz-x)^2 = 9y^2z^2 - 6xyz + x^2 \]

    因此

    \[ x'^2 + y^2 + z^2 = 9y^2z^2 - 6xyz + (x^2+y^2+z^2) \]

    由原方程 \(x^2+y^2+z^2 = 3xyz\) 代入：

    \[ x'^2+y^2+z^2 = 9y^2z^2 - 3xyz \]

    而

    \[ 3x'yz = 3(3yz-x)yz = 9y^2z^2 - 3xyz \]

    两者相等，故 \((x',y,z)\) 满足方程。正整数性由韦达定理保证。□

    3.1.3 对合性与名额排他性守恒¶

    韦达跳跃算子最重要的代数性质是对合性（Involution）：连续两次相同的跳跃回到原点。

    【定理 3.1.2（对合性定理）】 对任意 \(k \in \{x,y,z\}\)，

    \[ \hat{\mathcal{T}}_k^2 = \mathcal{I} \]

    \[ \hat{\mathcal{T}}_x(\hat{\mathcal{T}}_x(x,y,z)) = \hat{\mathcal{T}}_x(3yz-x,\, y,\, z) = (3yz-(3yz-x),\, y,\, z) = (x,y,z) \]
