## 五、向下推演：双缝现象的本体论解释

### 5.1 标准解释的困境

标准量子力学说：一个粒子同时通过了两条缝，与自身干涉。但"一个粒子"如何在物理上同时出现在两个位置？哥本哈根诠释回避这个问题，多世界诠释用平行宇宙来容纳，都不令人满意。

### 5.2 11T本体论图像

**入射过来的不是一个实物小球，而是一套超定域拓扑候选集合。**

具体过程：

1. **发射阶段**：源产生一个拓扑结构，该结构在超定域层面携带着完整的候选延展方向集合。此时它无质量、无惯性、不受光速约束。

2. **传播阶段**：拓扑候选集合中的各个构型根据全域压强约束，筛选适配的延展通道。两条缝对应的通道都满足压强约束（因为缝的几何结构对拓扑延展是开放的），因此**两条通道都被保留在候选集合中**。

3. **关键机制**：这不是"粒子分身走了两条路"，而是**拓扑候选集合在超定域层面同时包含了两条延展通道的构型**。由于超定域层面无时间，这两条构型不是先后经历的，而是**并存**的。

4. **到达观测屏**：当拓扑候选集合下沉投影到3S1T时，发生构型选择——具体选择哪条通道的构型，取决于屏上各点的局域拓扑压强分布。

5. **干涉条纹的形成**：大量同类拓扑候选集合重复投影，各候选构型之间的耦合（相长/相消）在3S1T中呈现为概率幅的干涉条纹。亮纹 = 多条候选构型相长叠加的区域；暗纹 = 候选构型相消抵消的区域。

### 5.3 与费曼路径积分的对应关系

费曼说：粒子走所有可能的路径，每条路径贡献一个相位因子 $e^{iS/\hbar}$，总和决定到达概率。

11T本体论说：拓扑候选集合在超定域层面包含所有适配压强的延展方向，投影下沉时各构型的耦合模式决定3S1T中的观测概率分布。

**数学映射**：费曼的"路径积分" $\int \mathcal{D}[x(t)] e^{iS/\hbar}$ 在本体论中是**超定域拓扑构型空间的压强约束条件下的投影测度**。相位 $S/\hbar$ 对应拓扑缠绕数的差异；路径求和对应候选构型集合的投影叠加。

### 5.4 可检验的差异化预言

如果这套图像正确，那么：

- **改变缝后拓扑环境**（例如在屏前加入电磁场或改变屏的几何结构），干涉图样的变化不应仅由"路径长度差"决定，还应体现出**拓扑压强约束的非局域性**——即改变远处边界条件也会影响近处的构型选择。
- **单粒子累积实验**：每个粒子到达屏的位置是拓扑投影的一次具体实现，但累积分布的统计结构由候选集合的耦合模式完全决定。这与标准量子力学预测一致（不矛盾），但提供了新的物理解释。
