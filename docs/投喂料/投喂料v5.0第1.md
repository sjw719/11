## 一、理论总览与核心定位

### 1.1 理论定义
「11时序矩阵大一统本体论」是一套原创的基础物理框架，核心范式为**双时空投影 + 能量一元本源**。整个体系以4条第一性公理为唯一底层假设，不引入任何额外的特设实体或自由参数，通过11阶时序矩阵的逐级运算，统一导出粒子物理、量子力学、引力理论、宇宙学四大领域的核心规律。

### 1.2 六大当代物理反常消解
本理论在不引入新实体的前提下，自然消解了当代物理学六大核心疑难：
1. **暗物质问题**：星系旋转曲线平坦由全体重子的根域斥力累积效应产生，无需暗物质粒子
2. **暗能量问题**：宇宙加速膨胀由超级宇宙尺度的密度梯度压强差驱动，无需暗能量场
3. **哈勃张力**：光速是局域密度依赖的可变函数，CMB时代与晚近宇宙光速不同，导致测量差异
4. **引力奇点疑难**：名额饱和Q_max硬上限，极端高密度下斥力绝对主导，无奇点发散
5. **正反物质不对称**：3T时空固有手性导致正反旋向能垒差，自然产生~10⁻¹⁰丰度差
6. **星系尖点问题**：核球粒子总数远少于大盘，κ_bulge ≪ κ_disk，斥力极弱，自然呈现核点分布

## 二、双机制核心规则（v4.0固化）

### 2.1 极化吸引效应（引力本源）
**物理本质**：总能量分布形成连续极化梯度场，投影等效为时空曲率。引力不是时空本身的弯曲，而是能量极化梯度在表象空间的投影读数。

**核心规则：引力看总量**
- 引力强度由总能量/总质量唯一决定
- 与能量分布的紧致程度（根的"大小"）完全无关
- 无论能量是弥散分布还是高度紧致，只要总质量相同，外部引力效应完全一致

**作用形式**：三维表象空间球对称通量稀释，严格遵循平方反比律1/r²，长程普适作用。

**对应主流理论**：广义相对论、牛顿万有引力均为本机制在弱场低速下的表象有效近似。

### 2.2 根域斥力效应（暗物质/暗能量/奇点消解共同本源）
**物理本质**：由公理3（名额排他性）派生的名额占位排斥效应，本质是空间位点的占位排斥，**不是第五种基本作用力**，没有对应的传递粒子，不属于规范相互作用范畴。

**核心规则：斥力看密度**
- 斥力强度由局域名额数密度唯一决定
- 单位体积内名额越多，排斥效应越强
- 能量越紧致（根越小），局域密度越高，斥力效应越显著

**作用形式的尺度二重性**：
1. **微观单点位**：势能为1/r³，对应力的衰减为1/r⁴，属于典型的短程效应，作用程极短
2. **宏观大尺度**：通过海量单元的短程效应叠加（压强梯度累积）表现为宏观长程效应，等效于连续介质的压强分布

**三大核心表现（同一机制跨尺度通用）**：
1. **致密天体核心支撑**：中子星、黑洞核心短程强斥力提供支撑压强，消解引力奇点
2. **星系轨道修正**：星系尺度全体重子斥力叠加修正轨道动力学，解释旋转曲线平坦性，替代暗物质
3. **宇宙膨胀驱动**：超级宇宙尺度密度梯度形成压强差，驱动外围膨胀加速，替代暗能量

### 2.3 常见误区红线（严禁出现）
| 错误表述 | 正确表述 |
|---------|---------|
| 根越小引力越弱 | 引力只看总能量，根紧致仅提升局域密度、增强斥力，与引力无关 |
| 根域斥力是长程力 | 单点斥力是短程的（1/r⁴），大尺度效应是压强累积的宏观表现 |
| 斥力是第五种基本力 | 斥力是名额排他的底层本底效应，不是独立规范相互作用 |
| 宇宙各向同性是视觉假象 | 是高精度的局部有效近似，全域普适性不成立，但绝非假象/错觉 |
| 本理论推翻了广义相对论/量子力学/标准模型 | 主流理论是本体系在特定极限下的高精度有效近似 |
