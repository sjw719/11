## 一、已归档工程核心结论（上）

### 工程七：正反物质不对称定量推导
- **定位**：微观拓扑首篇，3T手性机制定量落地
- **版本**：已归档V2.0

**核心公式**：
1. 正反旋向能垒差：ΔE_total(W) = 2χ·W·E₀(W)
2. 热平衡丰度比：n₊/n₋ = exp(ΔE_total / k_B T_dec)
3. 剩余正物质丰度（小量近似）：(n₊-n₋)/(n₊+n₋) ≈ ΔE_total / (2k_B T_dec)

**核心结论**：剩余丰度量级约10⁻¹⁰，与观测重子不对称自然匹配，无需精细调节。这是3T时空固有手性的必然结果，不是偶然的对称性破缺。

**参数**：χ为全域拓扑手性常数（无量纲，χ≪1），W为缠绕数，E₀(W)为基准拓扑束缚能，T_dec为弱退耦温度。

## 二、已归档工程核心结论（下）

### 工程十三：弱核力的拓扑衰变本质
- **定位**：微观相互作用首篇，弱作用拓扑本源
- **版本**：已归档V2.0

**核心结论**：弱衰变不是基本相互作用，是闭合时序拓扑失稳后的自发名额重分配瞬态效应。

**核心公式**：衰变寿命 τ_decay ∝ W / [χ·(κ - κ_cr)]

**衍生结论**：
1. 宇称不守恒本源：3T时空固有手性，拓扑衰变天然区分左右
2. 虚玻色子本质：拓扑重构过渡态的等效描述，不是独立传播粒子
3. 味的拓扑含义：对应拓扑缠绕数的不同本征值
4. 作用程极短：局域瞬态过程，无长程传播特性

**参数**：κ为瞬时饱和度，κ_cr为拓扑失稳临界饱和度。

## 四、核心变量定量公式总集

### 4.1 局域可变光速
c(ρ,Υ_μν) = c₀ / [1 + αρ + β·Tr(Υ_μν)]
低密弱场近似：c(ρ,Υ) ≈ c₀·[1 - αρ - β·Tr(Υ_μν)]

### 4.2 动态宇宙项
Λ(ρ) = Λ₀·(ρ/ρ_c)^(-1/3)
密度越低，等效Λ越大，斥力效应越显著；ρ→0时Λ不发散。

### 4.3 根域斥力全尺度公式
通用形式：F_rep(r) = K_base · κ(M) · M·m / r³

| 尺度 | κ取值 | 特征 |
|------|-------------|------|
| 微观粒子 | κ₀（单粒子本征） | κ₀≪1，斥力极弱，可忽略 |
| 恒星/致密星 | κ_sys = Nκ₀ + Δκ(ρ) | 存在小幅饱和偏移 |
| 星系尺度 | κ_gal = κ₀·N·f(M) | 暗物质效应的核心来源 |

### 4.4 致密系统等效质量偏移
M_sys = Σm₀,i + ΔM，ΔM = M₀·δ·(ρ/ρ₀)²
偏移量恒为正，低密度下可忽略，超核密度下显著。

### 4.5 正反物质不对称丰度
(n₊ - n₋)/(n₊ + n₋) ≈ ΔE_total / (2k_B T_dec) ~ 10⁻¹⁰

### 4.6 弱衰变寿命
τ_decay ∝ W / [χ·(κ - κ_cr)]

### 4.7 基底斥力耦合常数（标量层）
K_base = 3E_c λ_c³ / Q_max²

## 六、审计与规范体系

### 6.1 五条强制权限判定规则
1. **公理最高权限**：四条第一性公理拥有最高优先级，任何推导结论若与公理冲突，必须以公理为准，修正推导过程
2. **禁止外部实体**：不得引入体系外独立实体，包括但不限于暗物质粒子、暗能量场、引力子、轴子、超对称粒子等
3. **全尺度自洽**：同一物理机制必须跨尺度通用，不得为单一尺度增设独立规则
4. **禁止绝对化表述**：不得宣称本理论为"终极真理""已经证实"，需明确其为具备可证伪性的理论假说
5. **预言不得超纲**：定量预言需标注框架性、待标定，不得超出体系推导能力给出精确数值

### 6.2 五条错误红线（严禁出现）
1. ❌ 引力强度与根的紧致程度相关，根越小引力越弱
2. ❌ 根域斥力是可延伸至星系外围的长程力
3. ❌ 宇宙各向同性是视觉假象，观测到的均匀是错觉
4. ❌ 本理论推翻了广义相对论/量子力学/标准模型
5. ❌ 使用自创生造术语替代通用物理术语

### 6.3 与主流理论的兼容边界
- **广义相对论**：弱场低速、恒星外部引力场完全兼容；仅在奇点、大尺度斥力修正处存在差异
- **粒子物理标准模型**：所有已验证的粒子实验结果完全兼容；本理论解释了自由参数与对称性破缺的拓扑本源
- **ΛCDM宇宙学**：可观测宇宙内的演化、核合成、CMB等核心观测事实完全兼容；仅在创世奇点、暗物质暗能量本质、全域均匀性上存在底层差异

**核心立场**：不否定任何已验证的观测事实，只挑战对事实的底层解释；主流理论是本体系在特定极限下的高精度有效近似。
