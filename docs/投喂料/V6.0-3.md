## 一、宇宙学模型：超级宇宙水汽循环图景

### 1.1 核心架构
超级宇宙存在**超级中心**作为全域循环枢纽。从中心向外，根域基底名额密度单调递减，形成连续密度梯度场。整个超级宇宙是无始无终的稳态循环体系，宏观过程与地球水汽循环高度同构。

**多片区共存**：超级宇宙中同时存在无数处于不同演化阶段的片区宇宙，我们的可观测宇宙只是其中一个片区的局部。

### 1.2 四步闭环循环

| 循环环节 | 对应水循环 | 物理机制 | 核心规则 |
|---------|-----------|---------|---------|
| 基元蒸发 | 蒸腾上升 | 超级中心核心区将落入的宏观结构彻底粉碎为根域单量子基元，斥力压强梯度驱动细碎基元向外围弥散输送 | 斥力看密度，基元形态下斥力压强大于引力束缚 |
| 结构凝聚 | 遇冷凝结 | 外围区域密度降低，引力逐步主导，基元复合为粒子、原子、恒星、星系，形成局部片区宇宙 | 引力看总量，凝聚后质量增大，引力作用逐步凸显 |
| 质量沉降 | 降水回落 | 超大质量黑洞、巨型星系团等大质量结构，引力超过斥力压强，沿梯度向内沉降回落 | 总质量越大，引力累积效应越强，反向主导运动方向 |
| 重归粉碎 | 再蒸发 | 沉降结构进入核心区后再次被拆解为基元，重新被斥力向外输送，开启下一轮循环 | 极端高密度下斥力绝对主导，结构无法维持 |

### 1.3 我们的宇宙定位
- **所处阶段**：上升凝聚阶段的中后段，整体被斥力压强持续向外推动
- **对应观测**：整体向外运动表现为宇宙膨胀；晚期斥力净效应增强表现为加速膨胀
- **各向同性定位**：可观测宇宙（直径约930亿光年）远小于超级宇宙密度梯度特征尺度，局部密度差异极小，因此大尺度近似均匀各向同性。**这是高精度的局部有效近似，不是视觉假象/错觉**；其全域普适性不成立，超级宇宙存在明确的中心与径向密度梯度

### 1.4 循环核心特性
1. **无始无终**：符合净余能量不生不灭公理，没有创世时刻
2. **动态平衡**：粉碎输出速率与沉降回输速率长期匹配，整体稳态
3. **多片区共存**：无数片区宇宙同时处于不同演化阶段，生灭不息
4. **无奇点**：所有过程都是有限密度的物理过程，没有数学发散奇点

## 二、已观测反常解释清单

### 2.1 哈勃张力消解
**问题**：CMB测量（Planck H₀≈67.4）与近邻宇宙测量（SH0ES H₀≈73.0）存在约5σ差异。

**本理论解释**：光速是局域密度依赖的可变函数c(ρ)。
- CMB时代：宇宙整体密度高，c(ρ)显著低于当前值c₀，声学视界更小
- 晚近宇宙：密度降低，c(ρ)→c₀，光速接近当前测量值
- 二者不一致是可变光速的必然结果，不是真正的矛盾
- 不需要引入新物理，只是标准宇宙学假设光速恒定导致的表观张力

### 2.2 星系尖点问题解释
**问题**：ΛCDM暗物质晕预言星系中心密度尖点（ρ∝r⁻¹），但观测显示许多星系中心是平坦核点。

**本理论解释**：星系核球粒子总数远少于大盘，κ_bulge≪κ_disk。
- 核球斥力极弱，净力由引力主导，自然呈现平坦核点分布
- 大盘粒子数多，斥力累积效应显著，修正外区旋转曲线
- 不同星系类型的核球/盘质量比不同，尖点/核点表现因星系类型而异
- 无需引入暗物质的反馈机制等附加假设

### 2.3 暗物质直接探测零结果解释
**问题**：LUX、XENONnT等所有暗物质直接探测实验均持续零结果。

**本理论解释**：根本不存在暗物质粒子。所谓的"暗物质效应"是全体重子的根域斥力累积效应产生的动力学修正，不是由某种未知粒子提供的额外引力。直接探测实验寻找暗物质粒子，必然持续零结果。

### 2.4 正反物质不对称解释
**问题**：可观测宇宙几乎完全由正物质构成，标准模型无法自然解释。

**本理论解释**：3T时空具有固有手性，导致正反旋向拓扑结构存在能垒差ΔE_total=2χWE₀(W)。热退耦时自然产生约10⁻¹⁰的丰度差，量级与观测完全吻合，无需精细调节。不对称是时空内禀属性，不是偶然事件。

### 2.5 广义相对论奇点消解
**问题**：广义相对论预言黑洞中心与宇宙大爆炸起点存在密度无穷大的奇点。

**本理论解释**：名额饱和存在Q_max硬上限，任何位点的名额密度不能无限升高。极端高密度下斥力效应急剧增强，超过引力。全域粉碎是有限密度的物理过程，不是数学发散奇点。黑洞内部存在由斥力支撑的有限密度核心，不是奇点。宇宙没有大爆炸奇点，只有循环演化。

### 2.6 星系旋转曲线平坦性解释
**问题**：星系外围旋转速度不随距离下降，违反开普勒定律，标准解释为暗物质晕。

**本理论解释**：星系中全体重子的根域斥力累积效应，在大尺度上等效于额外的动力学贡献。斥力看密度，星系整体的名额分布产生等效压强场，等效压强梯度提供额外的向心力支撑。旋转曲线自然平坦，无需引入暗物质粒子。是同一根域斥力机制在星系尺度的表现。

## 三、分级可证伪预言体系

### 3.1 优先级划分
- **A级（近期可检验）**：现有技术可实现，10-20年内可出判决结果
- **B级（中期可检验）**：需下一代观测设备，30-50年内可实现
- **C级（远期可检验）**：当前技术无法实现，仅具备原则上的可证伪性

### 3.2 预言明细

| 预言名称 | 所属尺度 | 优先级 | 核心判决判据 |
| :--- | :--- | :--- | :--- |
| 星系旋转曲线远端开普勒衰减 | 星系动力学 | A级 | 星系外围旋转速度严格遵循v∝1/√r，无需暗物质晕参数 |
| 亚微米尺度引力偏离平方反比 | 微观引力 | A级 | 1-100微米区间存在额外排斥型修正，测量精度优于10⁻⁴可检出 |
| 中子星质量上限高于TOV极限 | 致密天体 | A级 | 观测到质量超过2.5倍太阳质量且非夸克星的稳定中子星 |
| 强相互作用残余CP破缺 | 微观粒子 | B级 | 测量到非零的中子电偶极矩，数值与手性预言匹配 |
| 黑洞候选体存在实体表面 | 致密天体 | B级 | 观测到吸积表面反射信号，或引力波余振存在超越无毛定理的多峰结构 |
| 宇宙加速膨胀演化偏差 | 宇宙学 | B级 | 高红移哈勃参数与ΛCDM存在系统性偏差，符合梯度压强模型 |
| 长程纠缠关联内禀衰减 | 量子效应 | C级 | 排除退相干后，天文尺度纠缠保真度低于量子力学预言 |
| 超大尺度星系密度偶极 | 宇宙学 | C级 | 全天星系数量密度存在180°系统性偶极，方向与CMB偶极一致，幅度随红移递增 |

### 3.3 核心证伪规则
1. 若1-100微米尺度引力严格符合平方反比律（精度优于10⁻⁴），则根域斥力短程机制不成立
2. 若证实黑洞存在严格事件视界且完全满足无毛定理，则致密天体奇点消解机制不成立
3. 若星系旋转曲线必须引入独立暗物质组分才能拟合，则星系尺度斥力修正机制不成立
