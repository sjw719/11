## 一、超级宇宙全域粉碎循环模型（水汽循环图景）
### 1.1 核心架构
超级宇宙存在**超级中心**作为全域循环枢纽，从中心向外根域基底名额密度单调递减，形成连续的密度梯度。整体为无始无终的稳态循环体系，宏观过程与地球水汽循环高度同构。

### 1.2 四步闭环循环

| 循环环节 | 对应水循环 | 物理机制 | 核心规则 |
|---------|-----------|---------|---------|
| 基元蒸发 | 蒸腾上升 | 超级中心核心区将落入的宏观结构彻底粉碎为根域单量子基元，斥力压强梯度驱动细碎基元向外围弥散输送 | 斥力看密度，基元形态下斥力压强大于引力束缚 |
| 结构凝聚 | 遇冷凝结 | 外围区域密度降低，引力逐步主导，基元复合为粒子、原子、恒星、星系，形成局部片区宇宙 | 引力看总量，凝聚后质量增大，引力作用逐步凸显 |
| 质量沉降 | 降水回落 | 超大质量黑洞、巨型星系团等大质量结构，引力超过斥力压强，沿梯度向内沉降回落 | 总质量越大，引力累积效应越强，反向主导运动方向 |
| 重归粉碎 | 再蒸发 | 沉降结构进入核心区后再次被拆解为基元，重新被斥力向外输送，开启下一轮循环 | 极端高密度下斥力绝对主导，结构无法维持 |

### 1.3 我们的宇宙位置
- 所处阶段：上升凝聚阶段的中后段，整体被斥力压强持续向外推动；
- 对应观测：整体向外运动表现为宇宙膨胀，晚期斥力净效应增强表现为加速膨胀；
- 各向同性定位：可观测宇宙（直径930亿光年）远小于超级宇宙梯度特征尺度，局部密度差异极小，因此大尺度近似均匀各向同性。**这是高精度的局部有效近似，不是视觉假象；其全域普适性不成立，超级宇宙存在中心与密度梯度。**

### 1.4 循环核心特性
1.  无始无终，符合净余能量不生不灭公理；
2.  动态平衡，粉碎输出与沉降回输速率长期匹配；
3.  多片区共存，超级宇宙中同时存在无数处于不同演化阶段的片区宇宙。

- **A级（近期可检验）**：现有技术可实现，10-20年内可出判决结果；

1.  若1-100微米尺度引力严格符合平方反比律（精度优于$10^{-4}$），则根域斥力短程机制不成立；
2.  若证实黑洞存在严格事件视界且完全满足无毛定理，则致密天体奇点消解机制不成立；
3.  若星系旋转曲线必须引入独立暗物质组分才能拟合，则星系尺度斥力修正机制不成立。

## 三、反常解释与边界兼容
### 3.1 核心观测反常解释
1.  **哈勃张力**：光速是局域密度依赖的可变函数。CMB时代密度高，$c(\rho)$显著低于$c_0$，声学视界更小；晚时宇宙密度低，$c(\rho)\to c_0$。二者不一致是可变光速的必然结果，不是矛盾。
2.  **星系尖点问题**：星系核球粒子总数远少于大盘，$\kappa_{\text{bulge}} \ll \kappa_{\text{disk}}$，核球斥力极弱，净力由引力主导，自然呈现平坦核点分布。
3.  **暗物质直接探测零结果**：不存在暗物质粒子，对应的观测效应由全体重子的斥力累积效应产生，因此直接探测实验必然持续零结果。

### 3.2 与主流理论的兼容边界
- **广义相对论**：弱场低速、恒星外部引力场完全兼容；仅在奇点、大尺度斥力修正处存在差异。
- **粒子物理标准模型**：所有已验证的粒子实验结果完全兼容；本理论解释了自由参数与对称性破缺的拓扑本源。
- **ΛCDM宇宙学**：可观测宇宙内的演化、核合成、CMB等核心观测事实完全兼容；仅在创世奇点、暗物质暗能量本质、全域均匀性上存在底层差异。

**核心立场**：不否定任何已验证的观测事实，只挑战对事实的底层解释；主流理论是本体系在特定极限下的高精度有效近似。

## 五、审计与投喂规范
### 5.1 代理机制
所有推导任务默认启动「元宝」专属审计代理，负责逻辑一致性校验与权限判定；输出内容需先经内部审计，确认符合公理、无矛盾、无越权后方可输出。若推导出现错误或偏离框架，代理需出具修正报告，说明错误点与修正依据。

### 5.2 强制权限判定规则
1.  **公理最高权限**：四条第一性公理拥有最高优先级，任何推导结论若与公理冲突，必须以公理为准，修正推导过程。
2.  **禁止外部实体**：不得引入体系外独立实体，包括但不限于暗物质粒子、暗能量场、引力子、轴子、超对称粒子等。
3.  **全尺度自洽**：同一物理机制必须跨尺度通用，不得为单一尺度增设独立规则。
4.  **禁止绝对化表述**：不得宣称本理论为“终极真理”“已经证实”，需明确其为具备可证伪性的理论假说。
5.  **预言不得超纲**：定量预言需标注框架性、待标定，不得超出体系推导能力给出精确数值。

### 5.3 错误红线（严禁出现）
1.  引力强度与根的紧致程度相关，根越小引力越弱；
2.  根域斥力是可延伸至星系外围的长程力；
3.  宇宙各向同性是视觉假象，观测到的均匀是错觉；
4.  本理论推翻了广义相对论/量子力学/标准模型；
5.  使用自创生造术语替代通用物理术语。
